# XOR Cryptography, Web Enumeration, and Earth CTF Labs

A searchable collection of Learn SecByte cybersecurity labs covering XOR cryptography, CyberChef exercises, web reconnaissance, hidden-path discovery, and HTTP/HTTPS security concepts.

This repository is designed for cybersecurity students, CTF players, penetration testers, SOC analysts, and security learners who want to practice cryptographic reasoning and web security investigation through hands-on cybersecurity labs.

## Introduction

CTF challenges offer structured opportunities to develop problem-solving and security analysis skills. This repository organizes the supplied labs by topic, making it easier to explore XOR operations, investigate web application paths, and understand how website configuration and transport security affect security assessments.

## Categories

- **Cryptography:** XOR operations, key discovery, and encoded-data analysis.
- **CyberChef:** Practical exploration of XOR transformations.
- **Web reconnaissance:** Hidden paths, website content discovery, and Gobuster.
- **Web configuration:** robots.txt and administrative portal investigation.
- **Transport security:** HTTP/HTTPS concepts and secure communications.

## Learning Path

1. Start with XOR Relay and XOR Echoes to explore XOR-based puzzles.
2. Practice data transformations using the CyberChef XOR lab.
3. Continue with XOR key discovery and hidden-data exercises.
4. Explore web content discovery through hidden paths, robots.txt, and Gobuster.
5. Finish with the HTTP/HTTPS investigation and review the security implications.

Adapt the sequence to the prerequisites and difficulty listed on each lab page.

## How to Use the Labs

1. Choose a lab from the index.

3. Review the learning objectives and instructions.
